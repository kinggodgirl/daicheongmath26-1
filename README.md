# 단원 마무리 — 원과 부채꼴

문제를 풀어 본 다음 시간에 쓰는 수업용 웹앱입니다. 학생은 패드(1인 1기기), 교사는 컴퓨터.
**학생이 스스로 문제를 골라** 진행하고, 교사는 누가 막혔는지 보고 돕습니다.

## 주소
- 학생용: `https://kinggodgirl.github.io/daicheongmath26-1/` (교사 화면의 [학생 주소 복사]를 쓰면 수업 코드가 자동으로 들어갑니다)
- 교사용: `https://kinggodgirl.github.io/daicheongmath26-1/teacher.html`
- 학생 화면 미리보기(연결 없이): `.../?demo=1`

## 학생 흐름 (문제마다)
1. **채점** — [정답 확인] 후 ○(맞음) / △(막힘) / ×(틀림)
2. **다시 풀기** — △·×인 문제는 힌트를 하나씩 열며 종이에 다시 풉니다. 다음 힌트까지 기다리는 시간이 있고(기본 60초),
   힌트를 다 보면 풀이도 열 수 있습니다. 다 풀면 [이제 풀 수 있어요] → 막힌 이유(개념/아이디어/계산) 선택.
3. **확인 문제** — ○였거나 다시 풀어 해결한 문제는 숫자만 바뀐 쌍둥이 문제가 열립니다.
   **책 덮고, 제출은 한 번**. 푸는 동안 그 문제의 힌트·풀이는 닫히고, 제출하면 바로 정답·풀이가 보입니다.

### 🧱 기초 연습 (도저히 못 풀겠을 때)
학생이 언제든 스스로 들어가는 1쪽 기초 유형 반복 연습입니다. 힌트를 다 봐도 못 푼 문제, 확인 문제를 틀린 문제에서는 관련 유형을 권합니다.
- 개념 빈칸 / 그림 보고 이름 고르기(예시·비예시) / 중심각과 호의 길이 / [반지름, 중심각]→호·넓이 / [반지름, 호]→넓이
- 문제는 매번 새로 만들어집니다. 답은 숫자만 입력(π는 칸 옆에 있음).
- 처음 두 문제는 단계를 따라 풀고, 그 뒤에는 바로 답을 냅니다. 틀리면 학습지의 풀이 순서대로 단계를 쪼개 다시 풉니다.
- 연속 3개 정답이면 ⭐.

## 교사 화면
- **🙋 지금 도울 학생**: 힌트를 다 보고도 못 푼 학생, 확인 문제를 틀린 학생(어떤 실수인지), 기초 연습에서 3번 연속 틀린 학생, 5분 넘게 진행이 없는 학생. 해결하면 자동으로 사라집니다.
- **문제별 현황**: 채점 분포, 다시 풀어 해결한 수, 확인 문제 정답률, 막힌 이유, 학생별 표.
  문제마다 `잠금(힌트 닫기) / 풀이 막기 / 풀이 허용(기본)`, 다음 힌트까지 기다리는 시간.
- **확인 문제**: 선택지별 분포 — 오답마다 어떤 실수에서 나오는지 적혀 있습니다.
- **🧱 기초 연습**: 유형별 정답률, ⭐ 학생 수, 자주 틀리는 단계, 학생별 최근 5문제.
- **✋ 전체 멈춤**: 함께 볼 때. **📺 크게 보기**: 이름 없이 문제별 해결 수만.

## 힌트·문제 고치기
`unit.js` 파일만 고치면 됩니다(문제·힌트·풀이·확인 문제·기초 연습 생성기). 교사 화면 [힌트·풀이 미리보기]에서 바로 확인하세요.
고친 뒤에는 `index.html`, `teacher.html`의 `APP_VER` 숫자를 둘 다 올려 주세요.

## 연결 (Firebase Realtime Database)
교사 화면과 학생 패드는 Firebase(프로젝트 `daicheong-math`)를 거쳐 기록을 주고받습니다. 기기끼리 직접 연결하지 않아서 학교 와이파이 제한을 받지 않고,
잠깐 끊겨도 기록을 모아 두었다가 다시 연결되면 올립니다. 설정값은 `firebase-config.js`.
- 데이터 위치: `classes/{수업 코드}/cfg`(교사 설정), `classes/{수업 코드}/stu/{이름}`(학생 기록·접속 표시)
- 데이터베이스 규칙은 `classes/{4자리 코드}` 아래에만 읽기·쓰기를 허용합니다.
- 다 쓴 수업 코드의 기록은 교사 화면 [🔄 초기화]로 지우거나 Firebase 콘솔에서 지울 수 있습니다.
