# 단원 마무리 — 원과 부채꼴

문제를 풀어 본 다음 시간에 쓰는 수업용 웹앱입니다. 학생은 패드(1인 1기기), 교사는 컴퓨터.
**학생이 스스로 문제를 골라** 진행하고, 교사는 누가 막혔는지 보고 돕습니다.

## 주소
- 학생용: `https://kinggodgirl.github.io/daicheongmath26-1/` (교사 화면의 [학생 주소 복사]를 쓰면 수업 코드가 자동으로 들어갑니다)
- 교사용: `https://kinggodgirl.github.io/daicheongmath26-1/teacher.html`
- 학생 화면 미리보기(연결 없이): `.../?demo=1` (단원 지정: `?demo=1&u=단원id`)
- 교사용 주소에 `?u=단원id`를 붙이면 그 단원으로 열립니다. 교사 화면 위쪽 단원 고르기로도 바꿀 수 있어요(단원이 2개 이상일 때 보임).

## 수업 종류 (교사 화면 📚 수업 종류)
- **복습** (기본): 지난 시간에 혼자 풀어 본 답이 있을 때. ① 채점(○△×)부터 시작합니다.
- **첫 차시**: 진도상 처음 배우는 날. ①이 **도전**으로 바뀌어 [다 풀었어요 → 정답 확인] 또는 [막혔어요 → 힌트로]를 고릅니다. 문제 목록 위에 "종이에 🎯 구할 것 · 📌 아는 것부터 적고 풀어 보세요" 안내가 뜹니다. 힌트 질문 답 칸과 확인 문제 답 칸 옆에 **🏳 포기** 버튼이 있어, 도저히 모르겠으면 정답을 보고 넘어갈 수 있습니다(포인트 없음, 교사 화면 도움 알림에 '포기'로 표시, 확인 문제는 틀린 것으로 남음). 나머지(힌트·확인 문제·기초 연습)는 같습니다.
- **🔀 섞어 풀기 열기**: 수업 끝 5분용. 학생 목록 위에 [시작하기]가 뜨고, 기초 유형을 섞은 4문제를 풉니다. 문제마다 먼저 "쓸 핵심 생각"을 고르고 답은 한 번만. 교사 화면 🧱 기초 연습 탭에 참여 수·정답률·핵심 생각 고르기 정답률이 보입니다.

## ⭐ 학습 포인트와 🎲 주사위 게임 (서로 따로)
- **⭐ 포인트**: 학생 위쪽 메뉴에 늘 보입니다. 제대로 학습한 행동에만 쌓이고 줄지 않아요. 규칙은 `points.js` 한 곳에서 정하며 학생·교사 화면이 같은 규칙으로 기록에서 계산합니다.
  힌트 질문 답 맞히기 +1 · 어디서 막혔는지 찾기 +1 · 다시 풀어 해결 +3 · 처음부터 맞히고 확인 문제까지 정답 +3 · 확인 문제 정답 +5 · 확인 문제 틀린 뒤 놓친 것 찾기 +1 · 재확인 문제 정답 +3 · 핵심 생각 맞히기 +2 · 기초 연습 정답 +1 · 기초 ⭐ +3 · 스스로 단계에서 형광펜 직접 켜기 +1 · 섞어 풀기 정답·핵심 생각 +1. 힌트를 열거나 ○를 누르는 것만으로는 0점.
  교사 화면 **⭐ 포인트** 탭에서 학생별 점수와 항목별 횟수를 보고, CSV에도 들어갑니다.
- **🎲 주사위 맞히기**: 포인트와 상관없는 별도 게임. 교사 화면 📚 수업 종류 카드의 [🎲 주사위 게임 열기]를 눌렀을 때만 학생 메뉴에 나타납니다(기본은 닫힘). 홀짝 맞히기(맞히면 동물 스티커, 1/2)와 숫자 맞히기(✨반짝 스티커, 1/6). 굴린 결과 막대그래프와 '맞힌 비율 vs 이론 확률'이 함께 보입니다.

## ⚾ 숫자야구 대전 (하 단계)
- 교사 화면 📚 수업 종류 카드의 [⚾ 숫자야구 대전 열기]를 누르면 학생 메뉴에 ⚾가 생깁니다. 한 판 최대 포인트도 거기서 정합니다(기본 10).
- 1~6 중 서로 다른 숫자 2개, 자리마다 ○(숫자·자리) △(숫자만) ×(없음). 두 사람이 동시에 추측하고, 먼저 맞히면 승리. 같은 회에 둘 다 맞히거나 10회 안에 못 맞히면 무승부. 6×6 후보 표에서 직접 지워 가며 추리합니다.
- 방 만들기 → 방 코드를 친구에게 알려 주거나, 친구가 '기다리는 방' 목록에서 바로 들어옵니다.
- **🤖 혼자 연습하기**: 같이 할 친구가 없으면 컴퓨터와 대결(약함: 아무 숫자나 · 보통: 가능한 숫자 중에서 · 강함: 가장 잘 줄이는 숫자). 포인트는 걸리지 않고 서버에도 남지 않습니다. 컴퓨터에게 남은 내 숫자 후보 수가 보여요.
- **학생별 열기/닫기**: 교사 화면 ⚾ 숫자야구 탭에서 학생 이름을 누를 때마다 그 학생만 열리거나 닫힙니다([모두 열기]/[모두 닫기]도 있음). 카드의 [⚾ 숫자야구 모두 열기/닫기]는 반 전체를 한꺼번에 바꾸고 학생별 설정을 지웁니다.
- **포인트 대전**: 두 사람이 고른 금액 중 작은 쪽(한 판 최대·둘의 보유 포인트 이하)이 똑같이 걸리고, 진 사람 포인트가 이긴 사람에게 갑니다. 보유 포인트 = 학습 포인트 + 대전 손익. 같은 친구와 연속 3판이 넘으면 연습 경기(0점). 경기 중 기권하면 패배.
- 비밀 숫자는 학생 기기에만 있고 서버에는 잠금값만 올렸다가 경기가 끝나면 공개합니다. **교사 화면이 두 사람의 비밀 숫자로 모든 ○△× 판정을 다시 확인한 뒤 정산**하므로, 교사 화면이 열려 있어야 포인트가 옮겨집니다. 교사 화면 ⚾ 숫자야구 탭에 진행 중 경기·학생별 승패·대전 손익·최근 경기가, ⭐ 포인트 탭과 CSV에 대전 손익이 나옵니다.
- ⚠ 이 기능은 데이터베이스 규칙에 `games`·`bank`가 추가되어야 동작합니다. `database.rules.json`을 Firebase 콘솔 규칙에 다시 붙여 넣어 게시하세요.

## 학생 흐름 (문제마다)
1. **채점** — [정답 확인] 후 ○(맞음) / △(막힘) / ×(틀림)
2. **다시 풀기** — △·×인 문제는 힌트를 하나씩 열며 종이에 다시 풉니다. 다음 힌트까지 기다리는 시간이 있고(기본 30초, 교사가 바로·20·30·45·60·90·120초 중 고름), 힌트 질문의 답(단원 파일의 `checks`)을 맞히면 기다리지 않고 바로 다음 힌트가 열립니다. **질문이 있는 힌트는 답하지 않고 시간만 기다려서는 넘어갈 수 없어요.** 맞히거나, 두 번 틀려 정답을 본 뒤(종이에 옮겨 쓰라는 안내)에야 다음 힌트가 열립니다. 질문은 숫자 칸 또는 보기에서 고르기(`ch`)입니다. 3번 넘게 틀리면 교사 화면 도움 알림에 적은 답과 함께 뜹니다. 문제·힌트·확인 문제·기초 문제 옆 **🔊** 버튼을 누르면 글을 소리 내어 읽어 줍니다(기기의 한국어 음성). 해결한 뒤 고르는 '막힌 이유'는 문제마다 다릅니다(단원 파일의 `causes`, 예: ③ "반지름 OC를 그을 생각을 못 했어요"). 
   - **🔎 어디서 막혔나 먼저 찾기**: ×·△를 고르면 힌트 전에 "어디서부터 정답과 달라졌나요?"를 고릅니다(문제마다 다른 보기). 고른 곳보다 앞의 힌트는 이미 아는 내용이라 열어 두고 그 다음 힌트부터 봅니다.
   - 힌트를 다 보면 풀이도 열 수 있습니다. 풀이를 본 학생은 [이제 풀 수 있어요]를 누르면 **풀이가 덮이고** 종이에 혼자 다시 쓴 뒤 [✔ 혼자 다 썼어요]를 눌러야 해결됩니다. 그다음 막힌 이유 선택.
3. **확인 문제** — ○였거나 다시 풀어 해결한 문제는 숫자만 바뀐 쌍둥이 문제가 열립니다.
   - **🔁 재확인 문제**: 확인 문제를 틀리고 '무엇을 놓쳤나요?'를 고르면, 원래 문제의 힌트·풀이를 다시 본 뒤 숫자가 또 바뀐 문제(단원 파일의 `TWINS2`)를 한 번 더 풉니다. 맞히면 그 문제도 완성(교사 화면에 '회복'), 또 틀리면 교사 화면 🙋 지금 도울 학생에 빨갛게 뜹니다.
   **책 덮고, 제출은 한 번**. 푸는 동안 그 문제의 힌트·풀이는 닫히고, 제출하면 바로 정답·풀이가 보입니다.
   - 답은 **직접 적습니다**(예: `8π-16`, `56/3π`, 비는 두 칸). 적은 값이 어느 오답과 같은지로 실수를 알아내고, 어느 것과도 다르면 '기타 답'으로 교사 화면에 그대로 보입니다.
   - ○로 채점했는데 확인 문제를 틀리면 "처음 답이 정말 이해해서 맞힌 것이었는지" 묻고, 교사 화면에 **과신**으로 표시됩니다.
   - 제출 뒤 **💡 이 문제의 핵심 생각 고르기**(다른 문제의 핵심 생각과 섞인 3개 중 하나). 돌아보기에 맞힌 수가 쌓입니다.

### 문제 목록에서
- **완성 막대**: 확인 문제까지 맞힌 문제 수(확인 문제가 없는 단원은 해결한 문제 수).
- **👉 다음에 해 볼 문제**: 푸는 중인 확인 문제 → 다시 풀던 문제 → 확인 문제만 남은 문제 → 아직 안 본 문제 순서로 하나를 추천.
- **🪞 나의 돌아보기**: 처음부터 맞힌 수·다시 풀어 해결한 수·확인 문제 결과, 내가 고른 막힌 이유와 그에 맞는 한 줄 조언, 확인 문제를 틀린 문제 바로 가기. 모두 완성하면 축하 문구.

### 🧱 기초 연습 (도저히 못 풀겠을 때)
학생이 언제든 스스로 들어가는 1쪽 기초 유형 반복 연습입니다. 힌트를 다 봐도 못 푼 문제, 확인 문제를 틀린 문제에서는 관련 유형을 권합니다.
- **📺 개념 영상**: 유형마다 1분 남짓한 개념 영상이 있어요(앱 안에서 그림이 한 장면씩 더해지고, 🦉 부엉 쌤 말풍선 자막이 한 글자씩 나오며 핵심 낱말·수는 색으로 강조. 소리 없음, 인터넷 영상 아님. 말풍선을 누르면 자막이 바로 다 나오고, 한 번 더 누르면 다음 장면). 유형 카드의 [📺 개념 영상]이나 문제 화면의 [📺 영상]으로 보고, 처음 푸는 유형에서는 "영상 먼저 보기"를 권해요. 마지막 장면의 [✅ 다 봤어요 → 문제 풀기]로 그 유형 문제로 바로 넘어가요. 멈춤·이전·다음이 있고, 끝까지 본 학생은 교사 화면 🧱 기초 연습 탭에 이름과 📺 표시로 보여요. 영상 내용은 단원 파일의 `BASIC_VIDEO`(장면마다 cap·say·add)에서 고칩니다.
- **성취감 장치**: 위쪽 **🎯 오늘 기초 정답** 막대(3개 🌱 · 6개 💪 · 10개 🏆), 유형 카드마다 성장 단계 **🌱 배우기 › 🌿 익히기 › 🌳 스스로**, **🏅 내 배지**(⭐·🌳 수). 단계가 오르거나 ⭐을 받거나 오늘 목표 칸에 닿으면 색종이 축하 화면이 3초 뜹니다(화면을 막지 않음).
- 개념 빈칸 / 그림 보고 이름 고르기(예시·비예시) / 중심각 비교 ① 몇 배 / 중심각 비교 ② 비 / [반지름, 중심각]→호·넓이 / [반지름, 호]→넓이
- 문제는 매번 새로 만들어집니다. 답은 숫자만 입력(π는 칸 옆에 있음).
- 도형 유형(B1·B2·C·D)은 매번 단계를 따라 풉니다. [0단계] 문제 문장에 형광펜 칠하기(구할 것 🎯빨강, 아는 것 📌파랑, "중심각의 크기가 60°"처럼 구절 단위로만 칠해짐) + 칠한 곳마다 개념 이름표(중심각·호의 길이·반지름·넓이) 붙이기 → [1단계] 중심각끼리 비교(**① 몇 배** 유형은 `100 = 50 × 2`처럼 배수, **② 비** 유형은 `50 : 70 = 5 : 7`처럼 비 — 두 유형이 따로 있어 학생이 골라 연습하고, 0단계 페이딩·⭐도 유형마다 따로) → [2단계] 호의 길이·넓이끼리 비교. 한 단계를 두 번 틀리면 정답을 보여 주고 다음 단계로 넘어갑니다. 그림만 있는 문제(약 40%)에서는 0단계가 그림 속 수마다 이름표 붙이기로 바뀝니다.
- **0단계는 점점 걷어 냅니다**: 유형마다 **배우기**(모든 단계 확인) → 2문제 연속 바로 맞히면 **익히기**(구할 것·아는 것만 표시하고 채점 없이 바로 답) → 다시 2문제면 **스스로**(안내 없음, [🖍 형광펜 켜기]는 선택). 틀리면 단계로 나눠 다시 풀고 한 단계 내려갑니다. 스스로 단계에서 형광펜을 직접 켜서 쓴 비율이 교사 화면에 "스스로 구·아"로 보입니다 — 0단계가 습관이 됐는지 보는 지표입니다.
- 연속 3개 정답이면 ⭐.
- 답은 3, 1.5, 3/2처럼 넣을 수 있고, 숫자가 아니면 틀림으로 치지 않고 다시 쓰라고 안내합니다.

## 교사 화면
- **🙋 지금 도울 학생**: 위쪽에 **함께 볼까요?** — 같은 문제에서 같은 곳에 막힌 학생이 3명 이상(그리고 반의 30% 이상)이면 이름과 함께 뜨고, [✋ 멈추고 함께 보기]로 바로 전체 멈춤.
  아래는 힌트를 다 보고도 못 푼 학생, 확인 문제를 틀린 학생(어떤 실수인지), 기초 연습에서 3번 연속 틀린 학생, 5분 넘게 진행이 없는 학생. 해결하면 자동으로 사라지고, 직접 도와준 뒤에는 [✓ 도왔어요]로 정리합니다(새로 막히면 다시 나타남).
- **문제별 현황**: 채점 분포, 다시 풀어 해결한 수, 확인 문제 정답률, 막힌 이유, 학생별 표.
  문제마다 `잠금(힌트 닫기) / 풀이 막기 / 풀이 허용(기본)`, 다음 힌트까지 기다리는 시간.
- **확인 문제**: 답별 분포 — 오답마다 어떤 실수에서 나오는지 적혀 있고, 어느 것과도 다른 '기타 답'은 학생이 적은 그대로 보입니다.
- **🧱 기초 연습**: 유형별 정답률, ⭐ 학생 수, 자주 틀리는 단계, 학생별 최근 5문제, 배우기·익히기·스스로 단계 분포, 섞어 풀기 결과.
- **👀 학생 화면**: 학생 패드와 똑같은 화면을 교사 화면 안에서 봅니다. 학생을 고르면 그 학생의 기록이 그대로 보이고, [학생이 보는 문제 따라가기]를 켜 두면 학생이 옮겨 가는 문제를 따라갑니다(기초 연습은 같은 유형의 새 문제). 여기서 누르는 것은 학생 기록에 남지 않습니다. [⛶ 전체 화면]으로 화면을 꽉 채워 TV에 띄울 수 있고, Esc나 [✕ 전체 화면 닫기]로 돌아옵니다.
- **✋ 전체 멈춤**: 함께 볼 때. **📺 크게 보기**: 이름 없이 문제별 해결 수만.
- **📐 그림 스타일**: 기본은 수능 시험지처럼 가는 선·작은 점·연한 색칠. TV·프로젝터로 띄울 때는 **굵은 선(프로젝터용)**으로 바꾸면 학생 화면 그림도 함께 바뀝니다. (스타일은 `common.css` 한 곳에서 정하므로 다른 단원 그림에도 그대로 적용)

## 기록
- 교사 컴퓨터 브라우저에 자동 저장됩니다. 반이 바뀌면 [⬇ CSV]나 [💾 백업] 후 [🔄 초기화]하세요.
- **다른 컴퓨터에서 이어 쓰기**: 교사 화면 [💻 다른 컴퓨터에서 이어 쓰기]를 열면 수업 코드와 **열쇠**(6글자)가 보입니다. 다른 컴퓨터의 교사 화면에서 같은 칸에 코드와 열쇠를 넣고 [가져오기]를 누르면 학생 기록과 설정이 그대로 이어집니다. 두 컴퓨터에서 함께 관리할 수도 있고, 한쪽에서 바꾼 설정(멈춤·잠금 등)은 다른 쪽에도 반영됩니다. 열쇠는 학생에게 보여 주지 마세요.
- 학생이 새로고침해도 **같은 이름**으로 들어오면 기록이 이어집니다.
- 이름은 자동으로 `번호 이름` 꼴로 정리됩니다. "7김민준", "07번 김 민준"은 모두 "7 김민준"이 되고, 번호 없이 이름만 쓰면 들어갈 수 없습니다.
- 그래도 한 학생의 기록이 두 이름으로 나뉘었다면 교사 화면 [🔗 두 기록 합치기]로 합칩니다. 합쳐서 없어진 이름으로 접속해 있던 기기는 첫 화면으로 돌아갑니다.
- 이름은 처음 들어온 기기가 차지합니다. 학생이 기기를 바꿨다면 교사 화면 학생 목록의 **🔓(기기 바꾸기)** 를 누른 뒤 새 기기에서 같은 이름으로 들어오면 기록이 이어집니다. 같은 이름을 다른 기기에서 쓰려고 하면 학생 화면에 안내가 나옵니다.

## 단원 (units 폴더)
- `units/list.js` — 단원 목록. 맨 위 단원이 기본값입니다.
- `units/{단원id}.js` — 단원 내용(문제·힌트·풀이·확인 문제·기초 연습). 지금은 `units/circle-sector-review.js`(원과 부채꼴).
- `units/_lib.js` — 모든 단원이 함께 쓰는 글자 꾸미기·교과서 형식 그림·문제 만들기 도구.
- `units/_template.js` — 새 단원 만들기 틀. 맨 위 설명대로 복사해서 씁니다.
- 단원마다 수업 코드·기록·설정이 따로 저장됩니다. 교사가 단원을 고르고 수업 코드를 알려 주면, 학생 화면은 그 코드의 단원으로 자동으로 열립니다.
- 기초 연습이나 확인 문제가 없는 단원도 됩니다. 없는 부분은 화면에서 빠집니다.

### 힌트·문제 고치기
해당 단원 파일만 고치면 됩니다. 교사 화면 [힌트·풀이 미리보기]에서 바로 확인하세요.
고친 뒤에는 `index.html`, `teacher.html`의 `APP_VER` 숫자를 둘 다 올려 주세요.

## 연결 (Firebase Realtime Database)
교사 화면과 학생 패드는 Firebase(프로젝트 `daicheong-math`)를 거쳐 기록을 주고받습니다. 기기끼리 직접 연결하지 않아서 학교 와이파이 제한을 받지 않고,
잠깐 끊겨도 기록을 모아 두었다가 다시 연결되면 올립니다. 설정값은 `firebase-config.js`.
- 데이터 위치: `classes/{수업 코드}/owner`(코드를 처음 연 교사 화면), `owners/{uid}`(열쇠로 들어온 교사 화면), `keys/{열쇠}`(이어 쓰기 열쇠, 교사만 읽음), `classes/{수업 코드}/cfg`(교사 설정), `classes/{수업 코드}/stu/{이름}`(학생 기록·접속 표시·기기 표시 `uid`)
- 학생 패드와 교사 화면은 **익명 로그인**으로 기기마다 보이지 않는 번호(uid)를 받고, 데이터베이스 규칙이 이 번호로 권한을 나눕니다.
  - 교사 화면: 처음 연 수업 코드의 주인이 됩니다. 그 반의 설정과 모든 학생 기록을 읽고 쓸 수 있습니다. 다른 브라우저에서는 열쇠를 넣어야 같은 코드를 관리할 수 있고, 열쇠 없이 같은 코드를 열면 새 코드가 만들어집니다.
  - 학생: 설정은 읽기만 하고, **자기 기록만** 읽고 쓸 수 있습니다. 다른 학생의 기록을 보거나 바꿀 수 없고, 전체 멈춤 같은 설정도 바꿀 수 없습니다.
- 규칙 파일: `database.rules.json` (Firebase 콘솔 → Realtime Database → 규칙에 붙여 넣어 게시)
- Firebase 콘솔 → Authentication → 로그인 방법에서 **익명**이 사용 설정되어 있어야 합니다.
- 다 쓴 수업 코드의 기록은 교사 화면 [🔄 초기화]로 지우거나 Firebase 콘솔에서 지울 수 있습니다.
