# 단원 마무리 — 원과 부채꼴

문제를 풀어 본 다음 시간에 쓰는 수업용 웹앱입니다. 학생은 패드(1인 1기기), 교사는 컴퓨터.
**학생이 스스로 문제를 골라** 진행하고, 교사는 누가 막혔는지 보고 돕습니다.

## 주소
- 학생용: `https://kinggodgirl.github.io/daicheongmath26-1/` (교사 화면의 [학생 주소 복사]를 쓰면 수업 코드가 자동으로 들어갑니다)
- 교사용: `https://kinggodgirl.github.io/daicheongmath26-1/teacher.html`
- 학생 화면 미리보기(연결 없이): `.../?demo=1` (단원 지정: `?demo=1&u=단원id`)
- 교사용 주소에 `?u=단원id`를 붙이면 그 단원으로 열립니다. 교사 화면 위쪽 단원 고르기로도 바꿀 수 있어요(단원이 2개 이상일 때 보임).

## 학생 흐름 (문제마다)
1. **채점** — [정답 확인] 후 ○(맞음) / △(막힘) / ×(틀림)
2. **다시 풀기** — △·×인 문제는 힌트를 하나씩 열며 종이에 다시 풉니다. 다음 힌트까지 기다리는 시간이 있고(기본 30초, 교사가 바로·20·30·45·60·90·120초 중 고름), 힌트 질문의 답(단원 파일의 `checks`)을 맞히면 기다리지 않고 바로 다음 힌트가 열립니다. 3번 넘게 틀리면 교사 화면 도움 알림에 적은 답과 함께 뜹니다. 
   힌트를 다 보면 풀이도 열 수 있습니다. 다 풀면 [이제 풀 수 있어요] → 막힌 이유(개념/아이디어/계산) 선택.
3. **확인 문제** — ○였거나 다시 풀어 해결한 문제는 숫자만 바뀐 쌍둥이 문제가 열립니다.
   **책 덮고, 제출은 한 번**. 푸는 동안 그 문제의 힌트·풀이는 닫히고, 제출하면 바로 정답·풀이가 보입니다.

### 문제 목록에서
- **완성 막대**: 확인 문제까지 맞힌 문제 수(확인 문제가 없는 단원은 해결한 문제 수).
- **👉 다음에 해 볼 문제**: 푸는 중인 확인 문제 → 다시 풀던 문제 → 확인 문제만 남은 문제 → 아직 안 본 문제 순서로 하나를 추천.
- **🪞 나의 돌아보기**: 처음부터 맞힌 수·다시 풀어 해결한 수·확인 문제 결과, 내가 고른 막힌 이유와 그에 맞는 한 줄 조언, 확인 문제를 틀린 문제 바로 가기. 모두 완성하면 축하 문구.

### 🧱 기초 연습 (도저히 못 풀겠을 때)
학생이 언제든 스스로 들어가는 1쪽 기초 유형 반복 연습입니다. 힌트를 다 봐도 못 푼 문제, 확인 문제를 틀린 문제에서는 관련 유형을 권합니다.
- 개념 빈칸 / 그림 보고 이름 고르기(예시·비예시) / 중심각과 호의 길이 / [반지름, 중심각]→호·넓이 / [반지름, 호]→넓이
- 문제는 매번 새로 만들어집니다. 답은 숫자만 입력(π는 칸 옆에 있음).
- 처음 두 문제는 단계를 따라 풀고, 그 뒤에는 바로 답을 냅니다. 틀리면 학습지의 풀이 순서대로 단계를 쪼개 다시 풉니다.
- 연속 3개 정답이면 ⭐.
- 답은 3, 1.5, 3/2처럼 넣을 수 있고, 숫자가 아니면 틀림으로 치지 않고 다시 쓰라고 안내합니다.

## 교사 화면
- **🙋 지금 도울 학생**: 힌트를 다 보고도 못 푼 학생, 확인 문제를 틀린 학생(어떤 실수인지), 기초 연습에서 3번 연속 틀린 학생, 5분 넘게 진행이 없는 학생. 해결하면 자동으로 사라지고, 직접 도와준 뒤에는 [✓ 도왔어요]로 정리합니다(새로 막히면 다시 나타남).
- **문제별 현황**: 채점 분포, 다시 풀어 해결한 수, 확인 문제 정답률, 막힌 이유, 학생별 표.
  문제마다 `잠금(힌트 닫기) / 풀이 막기 / 풀이 허용(기본)`, 다음 힌트까지 기다리는 시간.
- **확인 문제**: 선택지별 분포 — 오답마다 어떤 실수에서 나오는지 적혀 있습니다.
- **🧱 기초 연습**: 유형별 정답률, ⭐ 학생 수, 자주 틀리는 단계, 학생별 최근 5문제.
- **👀 학생 화면**: 학생 패드와 똑같은 화면을 교사 화면 안에서 봅니다. 학생을 고르면 그 학생의 기록이 그대로 보이고, [학생이 보는 문제 따라가기]를 켜 두면 학생이 옮겨 가는 문제를 따라갑니다(기초 연습은 같은 유형의 새 문제). 여기서 누르는 것은 학생 기록에 남지 않습니다. [⛶ 전체 화면]으로 화면을 꽉 채워 TV에 띄울 수 있고, Esc나 [✕ 전체 화면 닫기]로 돌아옵니다.
- **✋ 전체 멈춤**: 함께 볼 때. **📺 크게 보기**: 이름 없이 문제별 해결 수만.

## 기록
- 교사 컴퓨터 브라우저에 자동 저장됩니다. 반이 바뀌면 [⬇ CSV]나 [💾 백업] 후 [🔄 초기화]하세요.
- **다른 컴퓨터에서 이어 쓰기**: 교사 화면 [💻 다른 컴퓨터에서 이어 쓰기]를 열면 수업 코드와 **열쇠**(6글자)가 보입니다. 다른 컴퓨터의 교사 화면에서 같은 칸에 코드와 열쇠를 넣고 [가져오기]를 누르면 학생 기록과 설정이 그대로 이어집니다. 두 컴퓨터에서 함께 관리할 수도 있고, 한쪽에서 바꾼 설정(멈춤·잠금 등)은 다른 쪽에도 반영됩니다. 열쇠는 학생에게 보여 주지 마세요.
- 학생이 새로고침해도 **같은 이름**으로 들어오면 기록이 이어집니다.
- 이름은 자동으로 `번호 이름` 꼴로 정리됩니다. "7김민준", "07번 김 민준"은 모두 "7 김민준"이 되고, 번호 없이 이름만 쓰면 들어갈 수 없습니다.
- 그래도 한 학생의 기록이 두 이름으로 나뉘었다면 교사 화면 [🔗 두 기록 합치기]로 합칩니다. 합쳐서 없어진 이름으로 접속해 있던 기기는 첫 화면으로 돌아갑니다.
- 이름은 처음 들어온 기기가 차지합니다. 학생이 기기를 바꿨다면 교사 화면 학생 목록의 **🔓(기기 바꾸기)** 를 누른 뒤 새 기기에서 같은 이름으로 들어오면 기록이 이어집니다. 같은 이름을 다른 기기에서 쓰려고 하면 학생 화면에 안내가 나옵니다.

## 단원 (units 폴더)
- `units/list.js` — 단원 목록. 맨 위 단원이 기본값입니다.
- `units/{단원id}.js` — 단원 내용(문제·힌트·풀이·확인 문제·기초 연습). 지금은 `units/circle-sector-review.js`(원과 부채꼴).
- `units/_lib.js` — 모든 단원이 함께 쓰는 글자 꾸미기·교과서 형식 그림·문제 만들기 도구.
- `units/_template.js` — 새 단원 만들기 틀. 맨 위 설명대로 복사해서 씁니다.
- 단원마다 수업 코드·기록·설정이 따로 저장됩니다. 교사가 단원을 고르고 수업 코드를 알려 주면, 학생 화면은 그 코드의 단원으로 자동으로 열립니다.
- 기초 연습이나 확인 문제가 없는 단원도 됩니다. 없는 부분은 화면에서 빠집니다.

### 힌트·문제 고치기
해당 단원 파일만 고치면 됩니다. 교사 화면 [힌트·풀이 미리보기]에서 바로 확인하세요.
고친 뒤에는 `index.html`, `teacher.html`의 `APP_VER` 숫자를 둘 다 올려 주세요.

## 연결 (Firebase Realtime Database)
교사 화면과 학생 패드는 Firebase(프로젝트 `daicheong-math`)를 거쳐 기록을 주고받습니다. 기기끼리 직접 연결하지 않아서 학교 와이파이 제한을 받지 않고,
잠깐 끊겨도 기록을 모아 두었다가 다시 연결되면 올립니다. 설정값은 `firebase-config.js`.
- 데이터 위치: `classes/{수업 코드}/owner`(코드를 처음 연 교사 화면), `owners/{uid}`(열쇠로 들어온 교사 화면), `keys/{열쇠}`(이어 쓰기 열쇠, 교사만 읽음), `classes/{수업 코드}/cfg`(교사 설정), `classes/{수업 코드}/stu/{이름}`(학생 기록·접속 표시·기기 표시 `uid`)
- 학생 패드와 교사 화면은 **익명 로그인**으로 기기마다 보이지 않는 번호(uid)를 받고, 데이터베이스 규칙이 이 번호로 권한을 나눕니다.
  - 교사 화면: 처음 연 수업 코드의 주인이 됩니다. 그 반의 설정과 모든 학생 기록을 읽고 쓸 수 있습니다. 다른 브라우저에서는 열쇠를 넣어야 같은 코드를 관리할 수 있고, 열쇠 없이 같은 코드를 열면 새 코드가 만들어집니다.
  - 학생: 설정은 읽기만 하고, **자기 기록만** 읽고 쓸 수 있습니다. 다른 학생의 기록을 보거나 바꿀 수 없고, 전체 멈춤 같은 설정도 바꿀 수 없습니다.
- 규칙 파일: `database.rules.json` (Firebase 콘솔 → Realtime Database → 규칙에 붙여 넣어 게시)
- Firebase 콘솔 → Authentication → 로그인 방법에서 **익명**이 사용 설정되어 있어야 합니다.
- 다 쓴 수업 코드의 기록은 교사 화면 [🔄 초기화]로 지우거나 Firebase 콘솔에서 지울 수 있습니다.
