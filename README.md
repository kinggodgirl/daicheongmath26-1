# 단원 마무리 — 원과 부채꼴

문제를 풀어 본 다음 시간에 쓰는 **스스로 채점 → 힌트 보며 다시 풀기 → 확인 문제** 수업용 웹앱입니다.
학생은 패드(1인 1기기), 교사는 컴퓨터로 진행합니다.

## 주소
- 학생용: `https://<계정>.github.io/<저장소>/` (교사 화면의 [학생 주소 복사]를 쓰면 수업 코드가 자동으로 들어갑니다)
- 교사용: `https://<계정>.github.io/<저장소>/teacher.html`
- 학생 화면 미리보기(연결 없이): `.../?demo=1`

## 수업 흐름
1. 교사용을 열고 수업 코드를 알려 준 뒤, 학생이 **번호와 이름**으로 들어옵니다.
2. **1. 스스로 채점** — 문제마다 ○(맞음) / △(막힘) / ×(틀림). [정답 공개]를 누르면 학생 화면에 정답이 보입니다.
   [채점 결과] 탭에서 문제별 분포를 보고 설명할 문제를 고릅니다.
3. **2. 힌트 보며 다시 풀기** — 학생은 힌트를 하나씩 열고 종이에 다시 풉니다.
   - 다음 힌트까지 기다리는 시간(기본 60초)을 정할 수 있습니다.
   - 문제마다 `잠금 / 힌트만 / 풀이까지`. 풀이는 **'풀이까지'로 바꾼 문제만** 열립니다.
   - 학생이 [해결했어요]를 누르면, 처음에 △·×였던 문제는 막힌 이유(개념/아이디어/계산)를 고릅니다.
4. **3. 확인 문제(책 덮고)** — 쌍둥이 문제를 골라 열고, 학생이 제출하면 선택지별 분포가 보입니다.
   [정답 공개]를 누르면 학생 화면에 정답·풀이가 뜨고, 틀린 학생은 놓친 것을 고릅니다.
5. 📺 **크게 보기**는 이름 없이 결과만 프로젝터에 띄웁니다.

## 기록
- 교사 컴퓨터 브라우저에 자동 저장됩니다. 반이 바뀌면 [⬇ CSV]나 [💾 백업] 후 [🔄 초기화]하세요.
- 학생이 새로고침하거나 기기를 바꿔도 **같은 이름**으로 들어오면 기록이 이어집니다.

## 힌트·문제 고치기
`unit.js` 파일만 고치면 됩니다. 교사 화면의 [힌트·풀이 미리보기] 탭에서 바로 확인할 수 있어요.
파일을 고친 뒤에는 `index.html`, `teacher.html`의 `APP_VER` 숫자를 둘 다 올려 주세요.

## 학교 와이파이에서 연결이 안 될 때
`turn-config.js`에 중계 서버(Metered Open Relay) 앱 이름과 API 키를 넣으세요. (숫자 야구 대전과 같은 방법)
